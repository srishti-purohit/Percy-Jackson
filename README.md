# Percy Jackson

A little corner of the internet dedicated to a book series that I AM ABSOLUTELY OBSESSED WITH. 

This is a small fan website about the world of Percy Jackson and the Olympians by Rick Riordan. It has a bit about the premise, Camp Half-Blood, some of the characters, and the books. Basically, an excuse to spend time thinking about Percy Jackson and call it a coding project.

## Made with

- HTML
- CSS

## Why Percy Jackson?

Honestly, I just wanted to make something about a series I love. I like how the books mix mythology with the modern world, and how Percy can be facing the end of the world one minute and making a sarcastic comment the next. The characters, the friendships, the quests, all of it makes the series worth coming back to.

So here's a little website for a fictional boy who probably deserves a vacation more than anyone else in the entire series.

I made this site for Boba Bash Delhi!
